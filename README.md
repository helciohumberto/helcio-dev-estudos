# helcio-dev-estudos

Projecto de estudos Full Stack — desenvolvido durante o plano de 60 dias para conseguir o primeiro emprego dev em Portugal.

## O que está aqui

- **Backend** (`/`) — API REST com Node.js + Express + TypeScript + JWT + bcrypt
- **Frontend** (`/dia06-react`) — React + Vite + Tailwind + React Hook Form + Zod
- **Spring Boot** (`/animais-api`) — API em Java com Spring Security + JWT + PostgreSQL
- **Algoritmos** (`algoritmos.ts`) — FizzBuzz, Two Sum, palíndromo, frequência de caracteres

## Deploy ao vivo

- Frontend: [helcio-dev-estudos.vercel.app](https://helcio-dev-estudos.vercel.app/login)
- Backend: [helcio-dev-estudos-production.up.railway.app](https://helcio-dev-estudos-production.up.railway.app)

## Stack

Node.js · TypeScript · Express · React · Tailwind · Java · Spring Boot · PostgreSQL · Docker · JWT
